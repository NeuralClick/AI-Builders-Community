### SCENE 2 — What is an AI model?

**NARRATION:**

Now, you'll often hear another term: **AI model**.

Think of the model as the engine underneath the AI.

An AI model has been trained using large amounts of information so that it learns patterns.

For example, a language model learns patterns in language.

That allows it to take your input and generate a response that fits what you've asked it to do.

So the basic idea is:

**You provide an input. The model processes it. And you get an output.**

That's the mental model I want you to remember.

**Visualise it as a machine that transforms information into something useful.**

**VISUAL:**

Large central diagram:

**INPUT → AI MODEL → OUTPUT**

Input cards include: question, document, image.

Output cards include: answer, summary, draft.

**ANIMATION:**

Inputs enter the model one at a time. The model processes them, then outputs appear.
